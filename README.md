# ジム経営ギャップ診断 LP（デモ版）

パーソナルジム・小規模フィットネスジムの経営者向け「経営ギャップ診断付きランディングページ」のサンプルです。
数字を把握していない方でも答えられる設問形式で、**目指す姿と現状のギャップ**を可視化します。

- 数字がわからなくても回答できる（20問の選択式）
- 目指す月商に応じて「必要な水準」が変わり、そことの差が出る
- 詳しい数値がわかる方向けに、任意の入力欄も用意（折りたたみ）
- 診断結果はブラウザの印刷機能でA4・3ページのPDFとして保存可能
- サーバー／データベース不要（静的ファイルのみ）
- 入力データはブラウザ内でのみ計算され、保存・送信されません
- グラフは [Chart.js](https://www.chartjs.org/) v4（CDN読み込み）

## 診断の流れ

| STEP | 内容 |
| --- | --- |
| STEP 1 | 目指す月商・現在の会員数・平均単価をレンジで選択（3問） |
| STEP 2 | 5領域20問に4択で回答（収支の把握5／顧客の把握4／集客力4／継続力4／組織力3） |
| STEP 3 | 詳しい経営数値の入力（任意・折りたたみ） |
| 結果 | 売上ギャップ（年間）／理想への準備度／レーダー・不足ポイント／領域別の現在地／優先すべき3つ |

一人で運営している場合、組織力の3問は「一人で運営している」を選ぶと集計から除外され、レーダーも4軸で表示されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ構造（ファーストビュー／STEP1〜3／結果エリア／CTA） |
| `style.css` | デザイン（デザイントークン・レイアウト・レスポンシブ・印刷用） |
| `script.js` | 設問定義と診断ロジック（描画・集計・グラフ・PDF保存） |

## カスタマイズ

`script.js` の冒頭にまとまっています。

| 定数 | 内容 |
| --- | --- |
| `AXES` | 診断の5領域 |
| `SCALE_QUESTIONS` | STEP1のレンジ選択肢と、計算に使う代表値 `mid` |
| `QUESTIONS` | 20問の設問文・領域・改善アクション |
| `CHOICES` | 選択肢と配点 |
| `REQUIREMENTS` | 目指す月商のレベルごとに、各領域で必要となる水準 |
| `SAMPLE` | 「サンプル回答を入れる」で入る値 |
| `SUBMIT_ENDPOINT` | 回答の送信先（後述） |

## Googleスプレッドシートへの記録

`script.js` の `SUBMIT_ENDPOINT` に Google Apps Script のウェブアプリURLを設定すると、
診断実行時に回答一式が JSON で POST されます（空のあいだは送信しません）。

送信される内容は `buildSubmission()` が組み立てており、次の項目が1レコードになります。

- `submittedAt` / `storeName`
- STEP1の選択（`goalRevenue` / `members` / `unitPrice`）
- 集計値（`currentRevenue` / `gapAnnual` / `readiness` / `score_*`）
- 20問の回答（`f1`〜`t3`）
- STEP3の任意入力（`revenue` ほか）

Apps Script 側は `doPost(e)` で `JSON.parse(e.postData.contents)` を受け取り、
シートに `appendRow` する実装を用意してください。

## ローカルで確認する

`index.html` をブラウザで直接開くだけで動作します。
簡易サーバーで確認する場合は以下のいずれかを実行し、`http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
# または
npx serve .
```

## GitHub Pages で公開する

1. このリポジトリに `index.html` / `style.css` / `script.js` を push する
2. GitHub の **Settings → Pages** を開く
3. **Source** で `Deploy from a branch` を選ぶ
4. **Branch** に公開したいブランチ（例：`main`）と `/ (root)` を指定して **Save**
5. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

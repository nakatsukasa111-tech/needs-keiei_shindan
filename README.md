# ジム経営簡易診断 LP（デモ版）

パーソナルジム・小規模フィットネスジムの経営者向けの「簡易経営診断付きランディングページ」のサンプルです。
経営数値を入力すると、その場でKPI・グラフ・改善アドバイスが表示されます。

- サーバー／データベース不要（静的ファイルのみ）
- 入力データはブラウザ内でのみ計算され、保存・送信されません
- グラフは [Chart.js](https://www.chartjs.org/) v4（CDN読み込み）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ構造（ファーストビュー／入力フォーム／結果エリア／CTA） |
| `style.css` | デザイン（デザイントークン・レイアウト・レスポンシブ） |
| `script.js` | 診断ロジック（バリデーション・KPI計算・スコア計算・グラフ描画・アドバイス生成） |

## ローカルで確認する

`index.html` をブラウザで直接開くだけで動作します。
簡易サーバーで確認する場合は以下のいずれかを実行し、`http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
# または
npx serve .
```

## GitHub Pages で公開する

1. このリポジトリに `index.html` / `style.css` / `script.js` を push する
2. GitHub の **Settings → Pages** を開く
3. **Source** で `Deploy from a branch` を選ぶ
4. **Branch** に公開したいブランチ（例：`main`）と `/ (root)` を指定して **Save**
5. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## 注意

本ページは動作確認用のデモです。判定しきい値やスコア換算ロジックはサンプル値のため、
実運用時は `script.js` 冒頭の `THRESHOLDS` / `SCORE_BASE` / `ADVICE_RULES` を実態に合わせて調整してください。
